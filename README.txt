LOGBOOK – APP EDITOR VERSION

ZIP entpacken und index.html, manifest.webmanifest und sw.js direkt im Hauptordner deines GitHub-Repositorys ersetzen. Commit changes. GitHub Pages: main / (root).

Der Editor bietet gemeinsame Farbgestaltung, Hintergrund- und Kartenfarben, kompakte/komfortable Layouts, drei Button-Stile, bearbeitbare Reiterüberschriften und Buttonbeschriftung sowie eigene Infokarten je Reiter. Einstellungen gelten für alle Profile auf diesem Gerät und werden gemeinsam auf dem Gerät gespeichert. Editor-Konfiguration kann separat exportiert/importiert werden.

Vor dem Update bitte Trainingsdaten über Fortschritt > Daten sichern exportieren.
